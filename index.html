Como testar (2 minutos)

Use abas diferentes do mesmo navegador — todas compartilham o mesmo banco de dados.

  1. 1. Aba 1: cardápio da Mesa 05 → toque em Ver na mesa (3D/AR) → peça um hambúrguer.
  2. 2. Aba 2: entre como cozinha1 → Iniciar preparo → Pronto.
  3. 3. Aba 3: entre como garcom1 → o pedido aparece em “Prontos” → Entregue.
  4. 4. Aba 1: Conta → Solicitar fechamento.
  5. 5. Aba 4: entre como caixa1 → Abrir caixa → Mesa 05 → pagamento → Encerrar comanda.
  6. 6. Entre como admin para ver dashboard, relatórios, estoque e QR Codes.
